# 原创文案生成器 / Original Copy Generator

给一个行业关键词，先全网搜证，再把关键词扩成多视角，挖出你自己都没意识到的痛点；当不同来源说法打架时，它把冲突原话与出处摆出来让你拍板，绝不替你赌技术立场。每条观点可溯源，改写用受控换说法而不是逐句同义替换，一份真料同源出短视频口播、种草笔记、电商详情、公众号推文等多种文体。

A keyword-in, sourced-copy-out skill: it discovers real material on the web instead of inventing it, expands one keyword into six angles, surfaces conflicts for the user to resolve, and writes traceable, non-derivative copy with controlled paraphrase.

## 它解决什么

1. 普通 AI 文案从模型记忆硬编：易抄、易撞，遇到专业冲突自己瞎猜立场。
2. 用户自己也不清楚痛点：只给一个词、单角度搜索，越写越窄。
3. 逐句同义替换过不了平台查重：账号限流。

## 核心能力

| 能力 | 说明 |
|---|---|
| 搜证发现 | 给关键词就动，先检索再把词扩成多角度（故障 / 场景 / 对比 / 选购标准 / 误区 / 谁别买） |
| 冲突亮牌 | 来源打架时不选边，把争议原话与出处交给用户拍板 |
| 每句可溯源 | 每条观点带出处链接，无来源不开写 |
| 保原创 | 受控换说法，降低与已有内容的重复度 |
| 同源多文体 | 一份素材出短视频口播、种草笔记、电商详情、公众号文章、广告语 |

## 适用与不适用

适合：做内容、带货、获客的商家与个人，有产品但写不出「不抄」的文案，跨行业不想为每个行业重训模型。

不适合：想让模型凭空编数字、型号、案例与顾客原话的场景；某关键词搜不到任何真实来源时，本技能会要求换词，而不是硬写。

## 使用

在对话里给一个关键词或产品名，说明需要的文体与大致篇幅即可。技能自动完成检索、扩角度、融主线、成稿，并附来源清单。

## 边界

- 不保证播放、涨粉、传播、成交等任何效果。
- 不编造数字、型号、案例与顾客原话；公开来源冲突时不替用户选边。
- 无法联网检索或来源不足时，只输出已确证部分并明确标注，不虚构引用。
